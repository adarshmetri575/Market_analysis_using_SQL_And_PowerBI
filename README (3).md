# Customer Purchasing Behavior & Product Performance Analysis

## 📌 Project Overview

This project focuses on analyzing customer purchasing behavior and product performance using Excel, SQL, and Power BI. The analysis provides insights into customer orders, product demand, reorder patterns, and purchasing trends to support data-driven business decisions.

## 🛠️ Tools & Technologies

- Microsoft Excel
- SQL
- Power BI
- Data Cleaning
- Data Analysis
- Data Visualization

## 🎯 Project Objectives

- Analyze customer purchasing behavior.
- Identify high-demand products and departments.
- Analyze product reorder patterns.
- Understand order trends across different days and hours.
- Create interactive dashboards using Power BI.
- Generate actionable business insights.

## 📊 Key Insights

- The dataset contains 21 unique departments.
- The average order size is approximately 10.53 products per order.
- Fresh Vegetables and Fresh Fruits are among the highest-demand departments.
- Bananas and Organic Bananas show significant reorder activity.
- Customer purchasing activity is higher during daytime hours.
- Reorder patterns vary across different product categories.

## 📈 Project Analysis

The project includes 20 SQL-based analytical questions covering customer orders, product performance, reorder behavior, department analysis, and purchasing trends.

Power BI dashboards were created to visualize the findings and identify important business patterns.
